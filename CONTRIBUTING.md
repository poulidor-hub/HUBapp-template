# Contribuer à HUBapp_TEMPLATE

Ce dépôt est distribué sous licence **MIT** — les applications créées avec le
gabarit restent la propriété totale de leur auteur. Les conventions complètes
(CLA, style, releases) vivent dans le
[CONTRIBUTING.md du méta-repo POULIDOR](https://github.com/POULIDOR-Audit-Developpement/POULIDOR/blob/main/CONTRIBUTING.md).

1. Fork + branche par chantier (`feat/…`, `fix/…`).
2. Conventional Commits.
3. Tests (`ACTIONS/PYTHON/tests`, `frontend`) + docs à jour (`docs/`, CHANGELOG).
4. Bump de `VERSION` (`python3 scripts/bump_version.py patch|minor|major`) + entrée CHANGELOG.
