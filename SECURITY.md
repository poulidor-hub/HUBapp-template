# Politique de sécurité

**Ne pas ouvrir d'issue publique.** Signalez via le signalement privé GitHub
(*Security* → *Report a vulnerability*) — la politique complète vit dans le
[SECURITY.md du méta-repo POULIDOR](https://github.com/POULIDOR-Audit-Developpement/POULIDOR/blob/main/SECURITY.md).

- Précisez la version du template (`VERSION`) et les étapes de reproduction.
- Accusé de réception visé : 72 h ; divulgation coordonnée.
